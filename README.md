# tiltsemver

Tilt digests and semver fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/tiltsemver/

## Install / run

```bash
git clone https://github.com/theworker02/tiltsemver.git
cd tiltsemver
node src/cli.js
node --test
```
